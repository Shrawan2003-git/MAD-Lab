**Experiment 3 – Fragments in Android**
**Aim**

Develop an Android application using Fragments to create a flexible user interface.

**Objective:**
To implement two Fragments where

First Fragment displays a list of items.
Second Fragment displays details of the selected item.

Concept
**What is a Fragment?**

A Fragment is a reusable portion of the user interface that can be combined within an Activity.

Fragments help create responsive layouts for phones and tablets.

**Scenario:**

The application displays a list of programming languages.

When the user selects a language, its details are displayed in another Fragment.

Android SDK
Fragments
